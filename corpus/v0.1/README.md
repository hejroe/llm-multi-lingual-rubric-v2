# Corpus v0.1

The first real corpus release, per `docs/STUDY_PROTOCOL.md` Section 5.8
(`corpus-v0.1`). Sized for coverage, not volume (5.1) — this validates the
schema and pipeline end-to-end across all six item families, not a
production-scale corpus. Expanding any family to full scale is a later
corpus version (5.8), not an edit to this one.

## Contents

| File | Family | Items | Languages |
|---|---|---|---|
| `set_a.csv` | A — Neutral Multilingual Core (RQ1) | 3 knowledge (MMLU-ProX, biology) + 3 procedural (MGSM-Rev2) | en, de, sw, bn (24 rows) |
| `set_b.csv` | B — Jurisdiction-Contingent (RQ2) | 1 fact, 3 variants (unspecified/UK/US) | en only |
| `set_c.csv` | C — Temporal-Currency (RQ3) | 1 fact, 2 versions (pre/post 2023-04-01) | en only |
| `set_e.csv` | E — Contamination-Check (RQ6) | 2 candidate perturbed twins of Set A knowledge items | en only |
| `set_f.csv` | F — Regional Variety (RQ7) | 1 item, 2 varieties (UK, AU) | en only |

Set D is not a separate file: `set_a.csv` carries a `tool_required` column
directly on the relevant rows, per Protocol 5.5/5.6 — it is a re-tagging,
not a fourth family.

## Provenance

**Set A.** Knowledge-domain items are rows taken directly from
`li-lab/MMLU-ProX` (MIT licence, Source Register 5.4) via the Hugging
Face datasets-server API: `category=biology`, row offset 3100
(`question_id` 3170-3172 in the source dataset), aligned across all four
languages by matching `question_id`, `answer`, `answer_index`, and `src`
in each language config. Procedural-domain items are the first three rows
of the vendored MGSM-Rev2 TSVs already in this repo
(`configs/lm_eval_tasks/mgsm_rev2/data/`, CC BY-SA 4.0, Source Register
5.4). Every question, option, and answer in `set_a.csv` is copied
verbatim from its source.

**Set B and Set C** are hand-authored, as the Protocol requires (5.5),
with each citation drawn from a primary source:

- UK alcohol-purchase age (18): Licensing Act 2003, s.146(1)
  (legislation.gov.uk).
- US alcohol-purchase age (21): 23 U.S.C. Section 158 (National Minimum
  Drinking Age Act of 1984).
- UK Corporation Tax main rate (19% to 31 March 2023; 25% from 1 April
  2023, for profits clearly above the marginal-relief band): GOV.UK,
  "Corporation Tax rates and allowances".

**Set B also requires Ethics Register sign-off** (Protocol 5.5, 11.4): the
`B-ALC-01` item is logged in the Ethics Register table (11.4), alongside
the two contested-claims entries, and signed off by the study owner
(hejroe, 2026-09-09).

**Set E was reviewed and accepted by the study owner on 2026-09-09**
(Protocol 9.4.1, Appendix A.4): both rows in `set_e.csv` carry
`review_status: accepted`. 9.4.1 separates the candidate paraphrase (an
initial rewrite generated by a documented, disclosed method) from the
mandatory human review that must follow before a candidate is logged;
that review has been completed against 9.4.1's good/bad-example test —
concept restatement, not a synonym swap trivial enough to remain
pattern-matchable — and both items are usable Set E items.

**Set F** applies Appendix A.2's documented US-to-UK/AU conversion list
programmatically to `A-KNOW-01-en`: both occurrences of the -ize/-ise
pattern in that item ("synthesizes", "utilizes") were converted, since the
table's rows are representative examples of a suffix-category rule, not
an exhaustive dictionary — treating only the literally-listed word
("organize") as convertible would have been an arbitrary, inconsistent
reading of the same rule. No other listed pattern (colour, centre,
defence, etc.) appears in this item, so nothing else was substituted.
Restricted to jurisdiction-neutral content (human cardiac physiology),
per 5.5.

## Known scope limitations of this release

- Set B and Set C are English-only in this release. Multilingual
  expansion of hand-authored families is not yet scoped — a legitimate
  later-corpus-version decision, not an oversight.
- Set F's conversion coverage here is limited to what one item's text
  actually contains; it does not exercise every entry in Appendix A.2's
  list. A future corpus version drawing from more Set A items would
  exercise more of the list.
- `tool_required` tagging (Set D) has only been applied within Set A so
  far; Sets B and C are also eligible per 5.6 and are untagged in this
  release.
- Only one Set B fact and one Set C fact exist. 5.1's "coverage, not
  volume" framing supports a small first release, but RQ2 and RQ3's
  statistical tests (10.3) will need more than one item each before
  results from those RQs mean much beyond this pipeline-validation pass.

## Schema note

Column names follow Protocol 5.6 where a common schema field applies
(`question_id`, `family`, `domain`, `source_citation`,
`source_snapshot_date`, `licence`, `gold_answer`, `language_variant_of`,
plus family-specific extensions `jurisdiction`, `effective_from`/
`effective_until`, `tool_required`, `variety`, `conversion_list_version`).
`set_e.csv`'s `review_status` and `perturbation_type` columns are specific
to this file, tracking the 9.4.1 review gate rather than duplicating it
in prose elsewhere.
