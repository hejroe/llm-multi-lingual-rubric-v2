# 0003. Starting scale, not a ceiling

**Status:** Accepted
**Date:** 2026-09-08

## Context

Corpus size (5.1), the language set (6.5), and the model set (7.1) were
each, at one point during protocol drafting, read as fixed sampling
limitations — a cap on what the method could support. That framing was
identified and corrected during review.

## Decision

State explicitly, in each governing section (5.1, 6.5, 7.1) and here, that
running any item family, language, or model at full scale is expected
future use of this same method, not a special or unsupported case. Nothing
in the schema, rubric, or procedure is scale-limited by design; the pilot
sizes reflect development-stage practicality only.

## Consequences

Pilot-stage results must not be reported or interpreted as if they were a
final, full-scale study — every results write-up drawing on pilot data
needs to say so explicitly, and expanding scale later is a corpus/model/
language-set version change (5.8/6.5/7.5), not a methodology change.
